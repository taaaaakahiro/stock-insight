# 15 未実装要件

以下は現行の画面・API・テーブルとして提供していない。実装着手時に受け入れ条件と設計を確定し、現行仕様へ移す。権限の予定は[権限仕様](user-permissions.md)に集約する。

| 機能 | 必要な仕様・未確定事項 |
|---|---|
| 利用者・ログイン記録の管理画面 | 一覧の公開項目、検索、操作権限、利用停止の反映時間。現在は外部Clerkで許可を設定 |
| Clerk Webhook | 対象イベント、検証、重複処理、同期失敗時の再試行 |
| 名前付き検索条件・除外条件 | 本人別の保存形式、上限、編集・削除、URL条件との関係 |
| 株数・取得単価・メモ | 本人別の登録・更新、分割時の扱い、取得単価に基づく指標 |
| 警告しきい値・F5売り時条件 | 銘柄別／全体の優先順位、条件式、発火と解除、欠損値の扱い |
| F6画面通知・通知履歴 | 本人別の判定、重複抑制、既読、保存期間 |
| 管理者メール | 管理者の保有株と運用結果の通知、固定宛先、再送・失敗処理。一般向けメールは対象外の予定 |
| CSV書き出し | 本人の保有株・条件、項目、文字コード |
| 運用管理画面 | バッチ履歴、品質検証、使用量。現在のstatusは直近情報のみ |
| 退会・個人データ削除 | 操作者、関連データの削除範囲、ログ保持、バックアップの扱い |

現行コードには通知用Workflows、メール送信、退会API、これらの画面・保存テーブルはない。将来のAPIパス・DDLを現行の契約として先行定義しない。

推薦の配当込み評価、減配イベント集計、改善版の並走実験・自動採用は未実装。履歴保存と株価成績の比較は[実装済み仕様](16_recommendation_evaluation.md)を参照。
