# 15 現行機能の対象外

以下は提供していない。将来の仕様・権限・実装予定は定義しない。

| 分類 | 対象外 |
|---|---|
| 利用者管理 | アプリ内の利用許可管理、ログイン記録一覧、退会・個人データ削除、Clerk Webhook |
| 検索 | 名前付き検索条件・除外条件の保存 |
| ポートフォリオ | 株数・メモ・任意の取得単価の入力、警告しきい値の変更、自由な売り時条件、CSV出力 |
| 通知 | 画面通知・通知履歴・メール送信 |
| 運用画面 | バッチ履歴・品質・使用量の管理画面 |
| レコメンド評価 | 配当込み成績、減配イベント集計、改善版の並走実験・自動採用 |
| REIT分析 | 年間分配金・NAVの数値検証、訂正本文の自動統合、IR/PDF/OCR取得、分配込み系列、REITランキング |

取得日を指定した終値の自動取得は[実装済み](05_detailed_design.md)。REITの評価可能範囲は[REIT分析](17_reit_analysis.md)を参照。
