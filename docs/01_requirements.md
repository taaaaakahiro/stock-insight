# 01 要件定義

## 目的と利用者

日本の上場銘柄の株価、業績、配当方針を比較し、増配期待の検討と登録銘柄の確認を支援する。Google認証と利用許可を満たすユーザーのみ利用できる。管理者はスーパーユーザー、それ以外の許可済みユーザーは一般とする。操作可否は[権限仕様](user-permissions.md)に従う。

## 提供する機能

| 機能 | 現行の範囲 |
|---|---|
| F1 本人確認 | ClerkのGoogle認証、利用許可、ユーザー区分表示、ログアウト、認証情報再確認時のログ保存 |
| F2 スクリーニング | 株式・REIT・ETF、コード・名称検索、業種・市場・規模・指標・判定の絞り込み、並べ替え、50件単位の表示、URLで条件を再現 |
| F3 銘柄詳細 | 最新指標、直近5期の年次業績、最大20四半期の単独業績、株価・利回り推移、配当方針、REITの借入・物件情報 |
| F4 ポートフォリオ | 本人の銘柄を最大100件登録・解除し、現在の指標と固定の売り時サインを表示 |
| F7 AIレコメンド | コードの規則で最大10銘柄を選定・順位づけし、AIが説明を作成。共通結果を閲覧し、管理者のみ作り直し可能 |
| F8 データ鮮度 | 株価・財務の日付、直近バッチの日時・状態を表示し、未取得・失敗・更新停滞を警告 |
| 注目テーマ | 管理者が名前とキーワードを登録・編集・削除。有報の事業内容との一致を保存し、レコメンドの選定・表示に利用 |
| 日次取得 | JPX、J-Quants、EDINETから取得し、指標を計算・保存。外部サービスの運用権限で実行 |

F5（自由な売り時条件）・F6（通知）などの[未実装要件](15_unimplemented_requirements.md)は、上表の提供機能に含めない。

## データの範囲

- JPXの一覧を銘柄マスタとして株式・REIT・ETFを区別する。
- J-Quantsから日足終値、株式分割、通期・四半期の財務、配当予想を取得する。
- EDINETから有報・半期報告書の配当方針、有報の事業内容、投資法人の借入・物件情報を取得する。
- 計算可能なデータだけを表示する。不明値はゼロや否定に置き換えない。ETFなど財務を取得できない銘柄では指標が欠ける。
- 最新指標と複数ソースの更新は一括で確定しない。バッチ全体が完全同期したスナップショットではない。

取得元の契約・利用可能範囲はサービスの契約で管理し、コードのユーザー権限と混同しない。
