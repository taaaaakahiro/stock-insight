# 02 非機能仕様

## アクセスと情報保護

すべての `/api/*` は認証・利用許可を確認した後で処理する。管理操作はサーバー側でも拒否できる。本人データは認証されたユーザーIDで絞り込み、管理者にも他人のポートフォリオを扱う権限を付与しない。

シークレットはWorker Secrets・GitHub Actions Secrets・ローカルの未追跡ファイルに置く。CIでは全Git履歴をgitleaksで検査する。詳細は[設定仕様](06_secrets_and_repository.md)。

静的アセットのヘッダーは [web/public/_headers](../web/public/_headers) で設定する。CSP、HSTS、X-Frame-Options、X-Content-Type-Options、Referrer-Policyを含む。これらをAPIレスポンスにも一律付与する実装ではない。

## 応答と障害時の動作

- 共通参照の一部にWorker共有キャッシュ、ブラウザに最大300秒のキャッシュを使う。対象・無効化条件は[共通処理](05_detailed_design.md)。
- 個人情報、ポートフォリオ、レコメンド、テーマ、変更APIは `no-store`。
- 認証設定不足や、保存済み情報がなく認証基盤に問い合わせできない場合は503。保存済みの許可判定があれば問い合わせ障害中に再利用するため、許可解除の即時反映は保証しない。
- バックエンドの内部エラーはログへ記録し、通常のAPIエラー応答には内部情報を返さない。
- AI生成が失敗した場合、保存済みレコメンドを維持する。
- J-Quants・EDINET・REITの取得ジョブは別々に成功・失敗しうる。画面の直近バッチ状態だけでは、全取得元の成功を確認できない。

稼働率、最大応答時間、障害復旧時間の自動保証・測定基盤は実装されていない。個人別APIレート制限やAI再生成の日次回数制限もない。

## データ保持

| 対象 | 実装上の扱い |
|---|---|
| 株価履歴 | 取り込み時に過去5年と余裕期間へ切り詰める。詳細はデータモデル |
| 最新指標・銘柄マスタ | 銘柄ごとの現在値を保持 |
| 財務・配当予想・分割・REIT履歴 | 取得した履歴を保存。期間一律の自動削除処理はない |
| EDINET配当方針 | 銘柄・書類種類ごとの最新を保持し、新しい有報に包含される半期報告書と上場対象外の書類を整理 |
| 認証情報・ログイン記録・レコメンド | コードによる定期削除期限はない |
| R2原本 | バッチが圧縮保存・対象キー削除。保管期限のライフサイクル設定はリポジトリで定義していない |

ログイン記録にはユーザーID、メール、結果、時刻、IPアドレス、User-Agentを含む。退会に伴う自動削除は未実装。

## 運用と品質

CIの静的検査・テストを通し、公開対象を特定した作業ツリーからビルドする。DB変更前にはバックアップと互換性を確認する。[デプロイ](07_deploy.md)と[開発・検証](14_development_and_testing.md)を参照。

取得制限・料金・保存上限は外部サービスの契約による。特定時点の価格や無料枠をアプリ仕様として固定しない。
