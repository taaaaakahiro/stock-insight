# 株式レコメンドの財務加点（v2）

`graded-dividend-financial-v3`。既存の3段階評価と候補除外条件は維持し、同じ評価内では財務加点を優先して順位付けする。割安・財務健全性・稼ぐ力・配当余力を計算して上位10件を選び、AIに指標と同一書類の抜粋を渡す。点数は期待収益率や勝率ではなく、検証対象の初期方針。

| 項目 | 配点 | 条件 |
| --- | --- | --- |
| 割安 | 0–2 | 0 < PER ≤ 10で2点。10超は除外しない |
| 財務 | 0–3 | 現金・現金同等物 > 有利子負債で2点、現金 > 負債合計で1点、有利子負債/総資産 ≤ 20%で1点、自己資本/総資産 ≥ 50%で1点。合計は3点まで |
| 稼ぐ力 | 0–3 | 既存の5年通期黒字・増益傾向・同一書類の3年連続営業CFプラスに各1点 |
| 配当余力 | 0–2 | 0 < 配当性向 ≤ 50%で1点、営業CF＋投資CFで支払配当を賄えば1点。減配判定時は0点 |

財務の閾値は暫定の絶対基準。業種内順位による加点はまだ行わない。銀行・保険・証券・その他金融と業種不明は一般企業の財務/CF加点対象外。REITは既存の専用評価を維持。

## データと欠損

- EDINET年次CSVを既存の取得処理で読み、同一期・同一範囲（連結優先、連結の欠損を個別で補完しない）の円建て数値を抽出。
- 現金は現金・現金同等物。現預金・有価証券・売掛金を自動加算しない。
- 有利子負債は「有利子負債」「有利子負債合計」「有利子負債残高」の明示的な合計タグに限定。企業独自タグは認識済みの局所名のみ。借入金と社債の一部を合計して負債全額とみなさない。対応タグがなければ未確認となるため、初期の取得率は限定的。
- 自己資本はIFRS親会社所有者帰属持分、または純資産から明示された非支配株主持分と新株予約権を控除。控除項目が欠損なら未確認。
- 営業CF＋投資CFは設備投資だけを引いたFCFではない。投資CFがプラスの場合は資産売却益等の誤評価を避け、配当カバー加点をしない。
- 欠損・ダッシュ・非有限値・同項目の値の不一致は未確認。0とは区別する。取得できない項目で悪評価したり、得点率を水増ししたりしない。
- 推薦の株価日以前に提出され、期末が株価日以前18か月以内の有報を採用。同日提出の時刻まではCSV一覧の現行保存形式では区別しない。

## RAGと監査

同じ年次書類の配当政策・経営方針・経営者分析から、配当、設備投資、資金需要、返済、借入、減損、特別利益、現金に言及する文を最大6件、各240文字で取得する。監査用には6件を保持し、AI入力は最大2件・各100文字へ縮約して原値タグ一覧を除外する。数値は計算済み、文章は未信頼の根拠資料としてAIへ渡す。文中の指示には従わず、増配を断定せず、資料不足は未確認とする。全文検索/ベクトル検索や新たな外部LLMによる抽出は追加しない。

`edinet_docs.financial_quality_json` と既存R2書類に書類ID・提出日・対象期・連結範囲・タグ・コンテキスト・単位・原値・抜粋を保存。推薦時の入力および候補スナップショットには計算点数と根拠を固定し、履歴画面に内訳を表示する。現在の最新指標から過去の点数を再計算しない。

既存EDINET一覧処理の制約（訂正報告書・取り下げ後の既保存資料の再評価）は本変更では解消していない。原資料の網羅性や貸借対照表全体の照合が未確認のため、データ欠損率と原資料照合を確認しながら拡張する。

## 適用手順

1. バッチの既存マイグレーション処理で `0025_stock_financial_quality.sql` を適用する。
2. `sync-edinet` を実行。新規書類に加え、財務JSONがない既存年次書類を時間制限内で再取得する。次回は残りから再開する。
3. Workerを更新し、推薦を再生成する。既存履歴はそのまま保持する。
4. `batch-cli quality-report` で、業種別の財務JSON取得率と新旧ルールの順位差分（上位10件の入替・業種の偏り）を確認する。D1を読むだけで書き込まない。旧ルールとの成績差は引き続き推薦履歴で追い、取得率の偏りと順位への効きを見て配点を調整する。

本番反映と実データ再取得は別の操作。ローカルでのテストは本番の抽出率や投資成績を保証しない。

## 評価点・確認状況・懸念の表示

最新画面・履歴画面の共通表示に、推薦時の評価点（条件適合度）、財務情報の取得状況、数値上の主な懸念を並べる。最新画面の他の指標は更新されても、この評価は公開済み推薦と一致する保存済みスナップショットから読み、再計算しない。

確認状況は現金・有利子負債・負債合計・総資産・自己資本・営業CF・投資CF・支払配当・3年間の営業CF判定の9項目。取得済み/一部未確認/未確認/対象外を区別し、未確認項目を列挙する。条件不成立（false）や明示的な0は取得済みと数える。これはデータの充足度であり、信頼度や勝率ではない。

懸念は減配実績/予想、営業利益の前年同期比減少、営業CFマイナス、現金を超える有利子負債、営業CF＋投資CFによる支払配当の未充足を保存済み入力から判定する。財務・CFの条件は一般事業会社にのみ適用する。懸念で点数を追加減点する変更は行わない。

大型投資・返済計画等の文章は原資料へのリンクと抜粋で示す。キーワードだけで投資予定やリスクの存在を断定しない。空の懸念一覧は安全性の保証ではなく、古い履歴で判定がない場合は「記録なし」と表示する。プロンプト版は `explain-grade-financial-v2`、順位付けルール版は `graded-dividend-financial-v3`。
