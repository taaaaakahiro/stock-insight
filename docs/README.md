# stock-insight 仕様書

このディレクトリは、リポジトリのコードに対応する現行仕様と運用手順をまとめる。実装済みであることと、本番へ反映済みであることは区別する。経緯・作業記録・特定日の測定結果は仕様に含めない。

| 文書 | 管理する内容 |
|---|---|
| [要件定義](01_requirements.md) | 現在提供する機能と対象データ |
| [非機能仕様](02_non_functional_requirements.md) | セキュリティ、障害時の動作、保持と制約 |
| [システム構成](03_system_architecture.md) | 実行基盤、構成要素、データの流れ |
| [画面仕様](04_basic_design.md) | 画面、遷移、表示、操作 |
| [認証・キャッシュ・ポートフォリオ](05_detailed_design.md) | 共通処理と本人データの扱い |
| [設定・シークレット](06_secrets_and_repository.md) | 設定先、用途、公開リポジトリでの管理 |
| [デプロイ](07_deploy.md) | 公開前確認、本番反映、切り戻し |
| [指標仕様](08_indicator_sources.md) | データソース、計算式、配当方針の抽出 |
| [REIT仕様](09_reit_debt.md) | 金利・借入・物件の解析と表示 |
| [API仕様](10_api.md) | 全ルート、入力、応答、エラー、単位 |
| [データモデル](11_data_model.md) | 全テーブル・列・キー・索引・保存形式 |
| [AIレコメンド・テーマ](12_recommendations_and_themes.md) | 選定、説明生成、再生成、テーマ照合 |
| [バッチ運用](13_batch_operations.md) | 起動条件、ジョブ、再取得、障害対応 |
| [開発・検証](14_development_and_testing.md) | ローカル起動、モック認証、CI |
| [未実装要件](15_unimplemented_requirements.md) | 現行仕様に含まれない機能と未確定事項 |

計算式は指標仕様、認可は権限仕様、通信契約はAPI仕様、物理スキーマはデータモデルを正本とする。変更時は対応する文書と参照先を更新する。

## 用語

| 用語 | 意味 |
|---|---|
| 管理者 | `superuser`。一般向け機能に加えテーマ管理とAI再生成が可能 |
| 一般 | `general`。利用許可済みの管理者以外のユーザー |
| ポートフォリオ | 本人が登録した銘柄コードの集合。株数・取得単価は保持しない |
| DOE | このアプリでは1株配当÷BPSによる簡易的な株主資本配当率 |
| 利回りの過去5年比 | その銘柄の過去の週次利回りに対する現在の順位（パーセンタイル） |
| 配当方針の手がかり | EDINETの文章から規則で抽出した記述・数値。会社の履行を保証しない |
| 売り時サイン | ポートフォリオの固定条件による表示。自動売買は行わない |
