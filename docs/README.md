## 用語

| 用語 | 意味 |
|---|---|
| DOE | 株主資本配当率（配当金総額 ÷ 自己資本） |
| 配当利回りパーセンタイル | 現在の配当利回りが、その銘柄の過去10年の週次配当利回りのうち下から何%の位置か |
| YOC | 取得単価に対する配当利回り（Yield on Cost） |
| 有報 | 有価証券報告書 |
| 日次バッチ | 平日18:30 JSTに起動する取得・指標計算の処理（GitHub Actions上のRust CLI） |
| 判定Workflow | 日次バッチ完了後に動く、警告・売り時・AIレコメンド・通知の処理（Cloudflare Workflows） |

## 決定事項と次のステップ

実装前に決めるべき5点はすべて決まった。

- [x] ドメイン: maa-un.comのサブドメインだけを使う（stock.insight.maa-un.com）。PropFolioのClerkを無料のまま共用する
- [x] メール: 管理者だけの機能。宛先はシークレットで登録し、Cloudflareの検証済み宛先への無料送信を使う
- [x] 対象銘柄: 全上場銘柄
- [x] 決算短信の速報: 対象外
- [x] 株価・財務の取得元: J-Quants Light（月1,650円）。Yahoo Financeは使わない。EDINETは配当方針の文章（有報・半期報告書の最新1通ずつ）だけに使う。規約により当面は管理者1人で使う

- [x] インフラ: リソースはwranglerコマンドで作成し、当面はCloudflare側で管理する（あとでmaaun-terraformにimportするかもしれない）。デプロイとシークレットもコマンド（wrangler・gh）で行う
