# 12 AIレコメンド・テーマ仕様

## いつ・どこで見るか

株式のレコメンドは平日19:30 JSTに生成し、「AIレコメンド」タブへ表示する。当日のバッチ成功など、下記の生成条件を満たす場合のみ更新する。管理者は「作り直す」で手動更新できる。「履歴・成績」で過去の公開結果を閲覧する。

REITはこのランキングに含めない。日次取得後に別処理で分析し、REIT一覧と銘柄詳細へ表示する。[REIT分析](17_reit_analysis.md)を参照。

## レコメンドの選定

選定と順位はコードが決め、Workers AIは説明文を生成する。結果はユーザー別ではなく共通。

対象は株式のみで、次をすべて満たす銘柄。

- 配当利回りが0より大きく8%未満。
- バリュー株、または「5年連続配当あり」かつ「通期赤字なし」。
- 配当性向50%超・PBR1.5倍超・減配判定のいずれにも該当しない。配当性向・PBRが不明なだけでは除外しない。

### 評価

| 中間判定 | 条件 |
|---|---|
| clean | 通期赤字なしが真、かつ一過性利益判定が真ではない |
| recent | 直近四半期の営業増益率があれば正、なければ営業利益増加傾向が真 |
| year | 直近4四半期の営業増益率が不明または0以上 |
| solid | cleanかつrecentかつyear |
| fair | cleanかつyearかつ（recentまたは直近4四半期が増益） |
| cheap | バリュー株、または利回り評価が割安 |
| big gap | 配当方針の下限割れ、または方針に対する増配余地20%以上 |
| raise basis | 増配余地が正、連続増配2年以上、累進配当のいずれか |

`strong` はbig gap・solid・cheapすべて、`recommend` はそれ以外でraise basis・fair、残りは `watch`。

評価、テーマ該当の有無、下限割れの有無、増配余地、補助スコア、利回りの順で降順、最後にコード昇順で最大10件選ぶ。補助スコアはバリュー株・5年連続配当・通期赤字なし・四半期赤字なし・営業利益増加傾向の真の個数。具体的な判定は [recommend.rs](../crates/domain/src/recommend.rs) を参照。

## AI生成と保存

モデルは[共通定義](../crates/usecase/src/ai_config.rs)の `@cf/meta/llama-3.3-70b-instruct-fp8-fast`。REIT分析も同じ定義を参照する。候補の指標、良い点、注意点、配当方針、テーマなどを渡す。AIに順位や対象銘柄の決定を委ねない。

出力を検証し、対象外コードは採用しない。説明の整形後に空・200文字超・欠落した銘柄を落とし、5件未満なら生成失敗とする。採用した行は順位を詰めて保存する。AI呼び出し前に入力と上位最大50候補の指標を固定保存する。検証後は新しい公開履歴を確定し、最新表示用キャッシュの対象日の削除・挿入を同じD1バッチで行う。失敗時は旧公開版を維持する。

| 起動 | 条件・更新 |
|---|---|
| 平日19:30 JSTのActionsバッチ | 最新バッチが成功、終了がJST当日、株価日付あり、同じ株価日の結果なし |
| 管理者の作り直し | 最新バッチが成功、株価日付・候補あり。同日の既存結果やバッチ終了日では拒否しない |

手動再生成に日次回数上限はない。前提不成立は409、AI・検証・保存の失敗は500。保存日は株価の日付。保存列は順位・コード・説明・モデル・生成時刻・評価・生成元。最新画面の指標とテーマ名は現在値を結合する。履歴画面では生成時点のスナップショットを表示する。

実装: [生成usecase](../crates/usecase/src/recommend.rs)、保存（[Worker側](../crates/adapter-cf/src/d1_recommend.rs)・[Actions側](../crates/adapter-batch/src/d1_recommend.rs)）。

## テーマ

名前は最大30文字、キーワードは最大20個・各30文字。正規化で全角英数字と空白を整理し、空語・重複語を除く。名前は一意。入力順を保持する。

有報の `DescriptionOfBusinessTextBlock` から整形した先頭3000文字を `edinet_docs.business_text` に保存する。テーマ保存時、キーワードをこの保存文へ部分一致で照合する。大文字小文字を無視する検索ではない。複数語が一致した銘柄では先に一致した語を `matched_word` に保持する。

- 登録・更新時に対象テーマの対応を作り直す。
- 対応の削除と再挿入はD1バッチ。ただしテーマ本体の保存と再照合は別処理のため、再照合失敗時にも名前・キーワードの変更が保存されている場合がある。内容を確認して再保存する。
- 削除時はテーマ本体と対応をまとめて削除する。
- EDINETの更新だけではテーマ対応を自動再照合しない。新しい事業内容を反映するにはテーマを再保存する。
- 対応数は保存済みの一致件数。指標の取得済み件数や現在の上場銘柄数と必ずしも一致しない。

管理操作は管理者のみ。一般も閲覧APIとレコメンド内のテーマ表示を利用できる。実装: [theme domain](../crates/domain/src/theme.rs)、[themes usecase](../crates/usecase/src/themes.rs)、[照合SQL](../crates/adapter-cf/src/query.rs)。

## 履歴と成績

最新画面は現在の指標、履歴画面は生成時に固定した指標と理由を表示する。公開推薦・ルール上位10件・保存候補全体・1306を日次追跡する。現行方式はAIが順位を決めないため、公開推薦とルールの差をAIの選別能力と解釈しない。保存・比較・未実装範囲は[推薦履歴・成績比較](16_recommendation_evaluation.md)を参照。
