# 04 画面仕様

## ナビゲーション

| 画面 | URL・入口 | 表示と操作 |
|---|---|---|
| ログイン | 未ログイン時 | Googleログイン。利用未許可の場合は案内とログアウト |
| スクリーニング | 既定のタブ | 株式・REIT・ETF、条件、一覧、ページ切り替え |
| ポートフォリオ | `#portfolio` | 本人の登録銘柄、主・参考の売り時サイン、登録解除 |
| AIレコメンド | `#recommend` | 共通結果の順位・評価・説明・テーマ・指標・生成日時。管理者のみ作り直し |
| 注目テーマ | `#themes` | 管理者のみ表示。名前・キーワードの追加編集削除、該当銘柄 |
| 銘柄詳細 | `/stocks/<code>` | 指標、業績・株価・利回りの推移、配当方針、REIT詳細 |

ヘッダーにはユーザー区分、株価と財務の日付、取得日時を表示する。データ未取得・直近バッチ失敗・48時間を超える停滞で警告する。48時間は営業日換算ではない。フッターの版はCargo.tomlからビルド時に取得する。

## スクリーニング

検索条件をURLに保持し、URLから復元する。コード・名称、銘柄種類、業種・市場・規模、数値の範囲、判定フラグを組み合わせる。APIで受理する条件は[API仕様](10_api.md)を正本とする。

デスクトップはサイドバーと表、狭い画面はフィルターのシートとカードを使う。適用条件を表示し、個別解除・全解除ができる。1ページ50件。銘柄名から詳細へ移動し、星でポートフォリオに登録・解除する。不明な値は未取得として表示する。

配当方針のバッジから抽出文を開く。REITでは用途、変動金利・記載なし・金利見直しの比率、平均利率、稼働率を表示・絞り込みできる。

## 銘柄詳細

- 最新指標と配当が予想／実績のどちらかを表示する。
- 年次は最大5期、四半期は最大20期。四半期は累計を単独値に直して表示する。
- 株価と利回りは5営業日ごとの系列を使う。
- 配当方針は抽出文・数値と元書類を参照できる。PDFはプレビューで表示する。
- REITは借入・金利内訳・返済予定・決算推移・物件を表示する。[REIT仕様](09_reit_debt.md)を参照。

## 権限と表示

`/api/me` の `role` で区分を表示し、`permissions` でテーマ管理と再生成操作の表示を決める。一般ユーザーにもレコメンド内のテーマ名は表示する。テーマ閲覧APIの許可と、管理タブを表示する権限は異なる。

OSのカラーモードに合わせてライト／ダーク表示する。画面部品の実装は [App.tsx](../web/src/App.tsx) と [pages](../web/src/pages) を参照。
