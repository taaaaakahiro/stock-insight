# 17 REIT分析

REITの「収益の安定性」「借入の余裕」「価格の割安さ」と、用途別の価格動向を表示する。株式のAIレコメンドとは別機能で、REITのおすすめ順位は付けない。インフラファンドとETFは対象外。

## 実行と表示

| 項目 | 仕様 |
|---|---|
| 実行 | 通常は日次workflow成功後に専用の `reit-batch` が起動し、REIT取得後に実行。`REIT_RAG_ENABLED=true` の場合のみ |
| 画面 | 一覧のREITタブにセクター動向、銘柄詳細に3軸評価・検証済み数値・原文引用 |
| AI | 株式レコメンドと共通のWorkers AIモデル。[共通定義](../crates/usecase/src/ai_config.rs)を使用 |
| 閲覧 | 利用許可済みの一般・管理者とも可。画面では保存済み結果だけを読む |
| 初回・更新失敗 | 初回未生成はその旨を表示。更新失敗時は前回結果と基準日を表示 |

## 資料検索と生成

1. `reit_profile` が採用している有報のiXBRLをEDINETから取得し、証券コードを照合する。
2. 原本と解析結果を内容ハッシュ付きでR2へ保存し、D1に文書・本文の分割片を登録する。
3. 収益・借入・価格の論点ごとに語句検索する。日本語は文字2-gramを使用。設定があればVectorizeの意味検索も併用する。
4. 原文を最大500文字の引用候補に分け、AIが候補IDと論点を選ぶ。引用本文はプログラムで復元し、文書ID・論点・原文との完全一致を検証する。同じ入力の結果はキャッシュする。
5. 検証済み数値、根拠文、セクター計算値からAIが3軸評価を作る。状態・参照IDを検証し、不適合なら1回再生成する。
6. セクター解説を生成する。方向ラベルは計算結果と一致することを検証する。
7. 保存済み結果の銘柄・セクターの過不足、入力との一致、根拠・評価を再検証し、全件成功後に公開版を切り替える。古い実行で新しい公開版を上書きしない。

資料準備と銘柄別AI評価は分割ジョブで処理する。AI評価は共通の固定入力を使い、同じ実行IDなら完了済み銘柄を再利用する。公開までは途中結果を画面に出さない。

本文は最大900文字に分割し、表の先頭3行から最大400文字、前後の文章を各最大200文字添える。論点ごとに最大4件、計最大12件をAIへ渡す。他銘柄・別文書の検索結果は採用しない。

引用の一致は数値や説明の意味の正しさを保証しない。AIが抜き出した数値は、そのまま検証済み財務数値には採用しない。

## 3軸評価の範囲

状態は `positive`（余裕の目安あり）、`neutral`（中間）、`caution`（確認点あり）、`unavailable`（判定保留）。理由と参照IDを保持する。

| 軸 | 現行の制約 |
|---|---|
| 収益の安定性 | 年間分配金・一時要因の数値検証が未実装。確認点あり／判定保留のみ |
| 借入の余裕 | LTV・1年内返済比率・金利見直し比率の検証がそろうと中間／余裕の目安ありも許容 |
| 価格の割安さ | NAV構成要素・年間分配金の数値検証が未実装。確認点あり／判定保留のみ |

### 借入指標の検証

- 同一期末・JPY単位のiXBRL数値を使い、資産＝負債＋純資産を照合する。期末が未来、または270日超前なら使わない。
- 短期借入、長期借入と1年内返済分、投資法人債と1年内償還分を照合する。各内訳の欠損はゼロにしない。
- LTVは有利子負債÷総資産。返済比率は総額照合済みの1年内返済・償還額÷有利子負債。短期借入を二重加算しない。
- 金利見直し比率は明細照合済みの `reprice_1y`〜`reprice_1y_max` ÷有利子負債。範囲が20%・40%の判定境界をまたぐ場合、中間／余裕の目安ありを認めない。
- 「余裕の目安あり」を許容する条件はLTV≤45%、1年内返済比率≤20%、金利見直し比率の上限≤20%。条件を満たしてもAIに良好評価を強制しない。

これらはアプリ内の判定条件であり、投資成果や安全性を保証する基準ではない。

## セクターの価格動向

用途は [reit_sectors.csv](../data/reit_sectors.csv)。現在の構成銘柄へ期間の始点で等金額を配分した参考比較を計算する。分割・併合を調整し、分配金は含めない。公式指数や過去の構成を再現した運用成績ではない。

| 期間 | 上昇 | 横ばい | 下落 |
|---|---|---|---|
| 21取引日（約1か月） | +2%以上 | −2%超〜+2%未満 | −2%以下 |
| 63・126取引日（約3・6か月） | +5%以上 | −5%超〜+5%未満 | −5%以下 |

必要な価格が1銘柄・1日でも欠ければ、その期間の騰落率は未算出。3銘柄未満では数値が出ても方向を判定保留にする。上昇銘柄割合は期間リターンが正の銘柄数÷構成銘柄数。

基準日は当日の取引終了後、引け前の実行では前取引日。内閣府祝日と既存の取引日判定を使用する。AIには価格から原因・将来を推測しないよう指示する。

## 訂正と制約

訂正有報・取下げ・書類情報修正・不開示を監査し、親子関係をたどって関連する銘柄の評価を保留する。訂正本文の自動統合や、訂正撤回後の自動復活は行わない。

検索対象は採用有報のみ。発行体IR・PDF/OCR、月次リバランス指数、分配金込みの系列は未実装。過去に取得・保存していない資料の状態は復元しない。実モデルの品質・費用は自動テストだけでは検証できない。
